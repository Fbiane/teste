## Regras para o desafio

* Você pode pesquisar e adaptar soluções da internet, mas esperamos que você entenda o que fez e seja capaz de explicar as abordagens utilizadas.
* Faça a entrega através de um PR (pull request) neste repositório e nos avise enviando um e-mail para a pessoa que fez contato com você, colocando em cópia o e-mail seletivo.cdm@certi.org.br.
* Mesmo que não esteja com o desafio completo, nos envie o que conseguiu fazer até o momento e justifique no momento oportuno;
* Em caso de dúvidas sobre o desafio, envie um email para seletivo.cdm@certi.org.br.

## Dicas
* Vamos avaliar todos os aspectos da solução apresentada, então capriche na documentação, justificativas, organização e qualidade do código;
* Não esqueça do README.md com as instruções para rodar o projeto e descrições do que você fez!

## Desafio

### 1. Testes WEB
Considerando a seguinte página do site http://demo.automationtesting.in/Register.html  

#### 1.1 Testes exploratórios WEB
* Faça testes exploratórios com a finalidade de encontrar defeitos.
* Relate os problemas que você encontrou (evidenciando cada um).
* Armazene os arquivos em uma pasta chamada 11_testes_exploratorios_web

#### 1.2 Casos de teste WEB
* Escreva pelo menos 3 casos de teste, no formato e com as informações que julgar importantes.
* Armazene os arquivos em uma pasta chamada 12_casos_de_testes_web

### 2. Automação de testes WEB

* Para a mesma página do item 1, automatize pelo menos 3 casos de teste utilizando ferramentas de automação de tela (preferencialmente Robot Framework);
* Grave a tela com a automação executando e disponibilize neste repositório (o limite é de 100mb por arquivo);
* Disponibilize o código e escreva instruções de como executá-lo localmente;
* Armazene os arquivos em uma pasta chamada 2_automacao_web

### 3. Testes de API 
Considerando a seguinte API https://fakestoreapi.com/ 
* Elabore os casos de teste, execute os testes e forneça os resultados e evidências, estruturados da forma como você julgar conveniente.
* De preferência utilize a ferramenta Postman e disponibilize a coleção criada, bem como as respostas obtidas.
* Armazene os arquivos em uma pasta chamada 3_testes_api

Contemple os seguintes casos:
* Pelo menos 2 casos de teste que você considera básicos;
* Pelo menos 2 casos de teste que você considera intermediários;
* Pelo menos 2 casos de teste que você considera avançados;

Desejamos um bom desafio!
