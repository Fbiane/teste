# Desafio Técnico - QA

Este repositório contém o desenvolvimento de cenários e testes para um desafio técnico na área de Qualidade de Software, contemplando testes manuais, automação de testes Web e testes de API.

## Objetivo

O desafio consistiu em validar uma aplicação Web e uma API pública por meio de diferentes técnicas de teste, demonstrando conhecimentos em:

- Testes exploratórios
- Elaboração de casos de teste
- Automação de testes Web
- Testes de API
- Documentação de evidências

## Estrutura do projeto


- ProjetoTeste/
├── 2_automacao_web/
├── 3_testes_api/
├── 11_testes_exploratorios_web/
└── 12_casos_de_testes_web/


### 2_automacao_web

Automação de cenários da página:

http://demo.automationtesting.in/Register.html

Conteúdo:
- Código-fonte da automação
- Evidências da execução
- Instruções para execução local

Tecnologias utilizadas:
- Python
- Robot Framework
- Selenium WebDriver
- Pytest

### 3_testes_api

Testes realizados na API:

https://fakestoreapi.com/

Conteúdo:
- Casos de teste

- Evidências e resultados das execuções

### 11_testes_exploratorios_web

### 12_casos_de_testes_web

Documentação dos casos de teste elaborados para a aplicação Web.
